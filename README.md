## ✻ About me

Hi, I'm **Ashalinux** – a developer from Germany.

I build tools for **Minecraft servers** and the people who run them.

- Started with **Skript** on my own servers
- Grew that into dozens of complete server systems
- Now write my own **Java plugins** and **Skript addons**
- Run a **Proxmox** homelab and love **Linux**
- Build small **Discord bots** for my communities

<br />

## ✻ Building with Claude

I develop together with **[Claude](https://claude.ai)** – right in my terminal with **[Claude Code](https://claude.com/claude-code)**.

I bring the ideas and the Minecraft know-how. Claude helps me with the rest:

- **Plan** – talk through plugin architecture first
- **Code** – write and refactor plugins, scripts and bots
- **Debug** – hunt down the tricky bugs
- **Document** – turn notes into clean READMEs
- **Ship** – set up servers, Git and tooling

> Every line still gets read, tested and owned by me.

## ✻ Projects

### [SkBridge](https://github.com/Ashalinux/SkBridge)
Connects Skript, LuckPerms and Votifier. Ghost-free tablist teams, rank sync and a built-in vote listener.
`Java` `Paper`

### [SkVote](https://github.com/Ashalinux/SkVote)
A lightweight Votifier replacement for Skript – no extra plugins needed.
`Java` `Spigot`

### [skript-server-templates](https://github.com/Ashalinux/skript-server-templates)
60+ ready-to-use Skript systems: economy, shops, jobs, ranks and more.
`Skript` `SkBee`

### [proxmox-single-ip-nat](https://github.com/Ashalinux/proxmox-single-ip-nat)
Run all your Proxmox VMs and containers behind one public IP.
`Proxmox` `Networking`

### [discord-radio-bot](https://github.com/Ashalinux/discord-radio-bot)
A 24/7 radio station for your Discord voice channel.
`Python` `FFmpeg`

### [screen-session-picker](https://github.com/Ashalinux/screen-session-picker)
A friendly menu for your GNU screen sessions.
`Bash` `Linux`
