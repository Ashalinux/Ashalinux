## 👋 About me

Hey there! I'm **Ashalinux**, a developer from Germany who loves building things that make other people's lives easier — especially for **Minecraft server owners** and **communities**.

It all started with writing **Skript** for my own Minecraft servers. Over the years that turned into dozens of complete server systems — economies, shops, jobs, ranks, moderation tools and much more. At some point Skript alone wasn't enough, so I started writing my own **Java plugins and Skript addons** to fill the gaps I kept running into.

Besides Minecraft, I'm a big fan of **Linux** and self-hosting. I run my own **Proxmox** homelab, write small **Discord bots** for my communities and enjoy automating everything that can be automated. Lately I've also been experimenting with **real-time multiplayer games in the browser**.

## 🔭 What I'm working on

- 🌉 **[SkBridge](https://github.com/Ashalinux/SkBridge)** — my main project: a Paper plugin that connects Skript, LuckPerms and Votifier and finally gets rid of ghost prefixes in the tablist
- 🎮 **3D Core Multiplayer** — a real-time multiplayer 3D browser game with combat and levels *(private for now)*
- 🧩 Cleaning up and documenting my older scripts so others can learn from them
